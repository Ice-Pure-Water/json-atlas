# Privacy statement / 隐私说明

## Application behavior / 应用行为

- JSON Atlas parses and edits the text you provide inside your browser. It does not send document contents to an application server, analytics service, or AI service.
- Imported files are read by the browser. Export creates a local browser download.
- Open documents and comparison text are held in page memory. Reloading or closing the page clears them.
- The only value saved by the app in `localStorage` is the selected theme (`system`, `light`, or `dark`).
- The app does not set cookies, create accounts, or store document contents on the device.

## Hosting and browser boundary / 托管和浏览器边界

When you visit a hosted copy, the hosting provider may process ordinary connection metadata such as your IP address, request time, and requested static asset paths. Provider logs, browser extensions, injected scripts, and the behavior of modified/forked deployments are outside this repository's control. Review the policy of the host you choose, and use a trusted copy for sensitive data.

访问托管版本时，托管服务可能处理 IP 地址、请求时间和静态资源路径等常规连接信息。托管服务日志、浏览器扩展、注入脚本以及修改版或分叉版本的行为不受本仓库控制。请查看所用托管服务的隐私政策；处理敏感数据时，请使用可信的部署版本。

## For self-hosters / 自行部署

The project is a static client-side application. You may host the built files on infrastructure you control. This repository does not define or control that infrastructure's access logs, retention, CDN, or security configuration.

本项目是静态客户端应用。你可以将构建文件部署到自己控制的基础设施上。本仓库不定义或控制该基础设施的访问日志、数据保留、CDN 或安全配置。
