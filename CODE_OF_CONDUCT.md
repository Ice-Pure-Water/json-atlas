# Community guidelines / 社区行为准则

We want JSON Atlas spaces to be respectful, practical, and welcoming to people with different backgrounds and levels of experience. / 我们希望 JSON Atlas 社区尊重差异、务实友好，并欢迎不同背景和经验水平的参与者。

## Expected behavior / 应遵守的行为

- Be respectful and constructive. Critique ideas and code without attacking people. / 尊重他人，以建设性的方式讨论；可以批评观点和代码，不攻击个人。
- Assume good intent, ask clarifying questions, and accept corrections gracefully. / 善意沟通，必要时先澄清，并坦然接受修正。
- Keep discussions focused on the project and make space for other contributors. / 围绕项目讨论，为其他参与者留出表达空间。
- Protect privacy. Do not post secrets, personal data, or private user documents. / 保护隐私，不发布密钥、个人数据或用户私密文档。

## Unacceptable behavior / 不可接受的行为

Harassment, discriminatory language, threats, deliberate disruption, doxxing, and publishing another person's private information are not acceptable. / 骚扰、歧视性言论、威胁、蓄意破坏讨论、人肉搜索及公开他人隐私信息均不可接受。

## Enforcement / 执行方式

Maintainers may remove or edit harmful content and may restrict participation for behavior that violates these guidelines. To report a conduct issue, contact the repository maintainers through GitHub. For security issues, follow [SECURITY.md](SECURITY.md) instead. / 维护者可移除或编辑有害内容，并可限制违反本准则者参与社区。行为问题请通过 GitHub 联系仓库维护者；安全问题请按 [SECURITY.md](SECURITY.md) 私下报告。
