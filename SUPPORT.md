# Support / 使用帮助

## Questions and usage help / 使用问题

Read the [README](README.md) and [format guide](docs/FORMATS.md) first. For a reproducible bug, open a GitHub issue with the browser and operating system, input format, expected result, actual result, and minimal sample data. Remove credentials, personal information, and confidential content before sharing examples.

请先阅读[项目说明](README.md)和[格式指南](docs/FORMATS.md)。反馈可复现问题时，请提供浏览器和操作系统、输入格式、预期结果、实际结果及最小化示例。公开示例前，请删除凭据、个人信息和机密内容。

## Feature requests / 功能建议

Open a feature-request issue. Explain the use case and the formats or views involved. Avoid attaching private documents; a synthetic example is usually enough.

功能建议请使用 Feature Request 模板，说明使用场景及涉及的格式或视图。请勿上传真实的私密文档，通常用构造的示例即可说明需求。

## Security reports / 安全报告

Do not use public issues for security vulnerabilities. Follow [SECURITY.md](SECURITY.md) and submit a private GitHub security advisory.

安全漏洞不要通过公开 Issue 报告，请按 [SECURITY.md](SECURITY.md) 提交私密安全公告。
